Pakr — Headless / Manual Build Mode

This repository is configured to run builds from GitHub Actions. The frontend UI has been removed in this branch. To trigger a build, use the repository workflow or update the configuration file.

How to run

  1. Edit .github/build-config.json and set app_url, app_name, and package_name as needed.
  2. Go to GitHub → Actions → "Build APK" workflow → Run workflow. If you leave inputs empty, values from .github/build-config.json will be used.
  3. After the workflow finishes, download artifacts (APK) from the workflow run page.

Sample .github/build-config.json

{
  "app_url": "https://zs.rednet.cn/calendar.html",
  "app_name": "MyCalendar",
  "package_name": "com.zs.calendar",
  "version_name": "1.0.0",
  "icon_url": ""
}

Secrets for signing (KEYSTORE_BASE64, KEYSTORE_PASSWORD, KEY_ALIAS, KEY_PASSWORD) should be set in repository Settings → Secrets and variables → Actions.
